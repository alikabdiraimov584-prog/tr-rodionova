# Путь покупательницы и точки отвала

Интерактивная карта: https://claude.ai/artifact/Bc4Arzvy6Hx3zQeVkcf2u3 (10 этапов, воронка, приоритеты). Проход по боевой сборке на телефоне 390 px, 4 октября 2026.

## Критичные точки отвала
1. **Измерение.** Собственная аналитика пишет события только после «Принять» в cookie-баннере; на стенде 0 событий. Решение: обезличенную статистику без третьих лиц считать необходимой (решение юриста), Метрику и GA оставить по согласию.
2. **Корзина требует входа.** «В корзину» гостем ведёт на регистрацию из 5 полей и 2 галочек. Решение: гостевая корзина, вход кодом по e-mail/телефону на шаге оформления, аккаунт Circle создаётся с первым заказом (решение бренда).
3. **Оформление.** Одна длинная страница, итог и кнопка внизу, свободный ввод адреса. Решение: 3 шага, закреплённый итог, подсказки адреса.
4. **Оплата отдельным шагом.** После подтверждения заказа нужно было ещё раз нажать «Оплатить». ✅ Исправлено: при онлайн-оплате сразу открывается платёжная страница провайдера (`checkoutAction`).

## Трения
- Cookie-баннер занимал 40 % экрана телефона. ✅ Исправлено: компактный баннер 97 px.
- Карточка товара: нет условий доставки/примерки/возврата под кнопкой и блока «С этим носят».
- Нет напоминания о неоплаченном заказе до снятия резерва (24 ч).
- Нет письма после получения с просьбой об отзыве.
- Доставка без интервала времени; примерка не предложена по умолчанию в Москве.
